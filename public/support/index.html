Suporte

Última atualização: 1 de novembro de 2026 · English version below

O Deck conversa com o agente de IA do seu servidor; é preciso ter um servidor com o agente instalado para usar o app.

Primeiros passos

  1. Crie sua conta e entre.
  2. Na tela inicial, copie o comando de pareamento e rode-o no seu servidor Linux.
  3. Cadastre seu aparelho com o código mostrado pelo servidor e abra o chat.

Problemas comuns

  • Caixa offline: confira se o serviço deck-agent está rodando no servidor e se ele alcança a internet.
  • Código de pareamento expirado: gere um novo na tela inicial (vale por 10 minutos).
  • Sem resposta do agente: o agente precisa estar logado no provedor de IA dele no servidor.

Support

Last updated: November 1, 2026 · Versão em português acima

Deck talks to the AI agent on your server; you need a server with the agent installed to use the app.

Getting started

  1. Create your account and sign in.
  2. On the home screen, copy the pairing command and run it on your Linux server.
  3. Enroll your device with the code the server shows and open the chat.

Common problems

  • Box offline: check that the deck-agent service is running on the server and reaches the internet.
  • Pairing code expired: generate a new one on the home screen (valid for 10 minutes).
  • Agent does not answer: the agent must be signed in to its AI provider on the server.
